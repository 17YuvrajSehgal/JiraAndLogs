# Experiments

One folder per task (e.g. `t1_1/`). Each run keeps:

- the code and config used (or the git commit),
- the random seed,
- where it ran (laptop or cluster + SLURM job id),
- the raw output and the plots,
- a short `RUNLOG.md` line: date, command, result, note.

A failed run is kept and logged too. It is evidence.
